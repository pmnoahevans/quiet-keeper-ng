# quiet-keeper-ng

Platform engineer · Zig and bare metal


## 用法

```bash
cat data.txt | node index.js
```

输出：

```
   3  error: timeout
   1  warn: retry
---
2 unique / 4 lines
```

## 安装

```bash
git clone https://github.com/pmnoahevans/quiet-keeper-ng.git
cd quiet-keeper-ng
npm install
```

## 为什么写这个

现成的工具太重，装一堆依赖不划算。
